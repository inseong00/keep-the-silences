Target types

Every prompt on this page names one source inside a clip that has several. The annotation labels each target by when it is active, and each sample below carries its badge.

onset or span

The target sounds only during part of the clip; the rest of it should be silence. Listen to the gaps as well as to the events.

ambience

The target sounds throughout the clip, so there is no silence to keep.

Samples

Ten targets from five test clips — seven onset or span, three ambience. Each row is one text prompt, and each tile below it plays that clip's video with one system's audio on it. Starting a tile stops the others. Audio is never loudness-normalised: how quiet a system goes is the point.
